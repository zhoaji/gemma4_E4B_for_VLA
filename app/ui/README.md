# 用户界面

主界面为 `Mulitiple_model_UI.html`。文字/图片可访问 `http://<Jetson-IP>:8001/`；需要
麦克风时访问 `https://<Jetson-IP>:8443/` 并信任证书。UI 自动代理模型与 ASR，并每 3 秒刷新状态。

Gemma 请求使用 SSE 流式输出，回复会边生成边显示。语音输入不使用流式切片：点击停止后才
提交完整录音，转写完成后写入输入框。ASR 自动处理中英混说，并统一将中文转换为简体；不保存原始录音。

点击“＋ 新对话”会创建独立记忆；当前浏览器标签页的多轮文本对话会持续带入近期记录。旧记录超过
20 条消息或约 9000 字符后由本地模型压缩为偏好、事实、决定和待办摘要，避免上下文持续膨胀。云端模式不使用本机记忆。
