# 大脑层

调用本地 E4B API，管理提示词、工具定义、意图判断与结构化决策。`monitor/` 是 8001/8443
边缘入口；`asr/` 是按需 Whisper 语音识别。未来动作控制应扩展边缘服务，避免端口冲突。

## 会话记忆

本机记忆由 `monitor/server.py` 管理，数据位于 `data/memory/conversations/`。每个 UI 会话有独立
UUID，新建对话不会带入旧会话。每轮保存用户与模型文本；超过 20 条消息或约 9000 字符时，用本地
E4B 压缩旧记录，保留“用户偏好、事实/决定、未完成事项、项目配置”摘要与最近 10 条消息。
摘要仅在同一会话作为系统背景注入，不发送到云端模式。
