# ASR 语音调试台

这是现有 ASR 服务提供的独立页面，不另外启动模型，不需要安装前端依赖。

## 打开页面

先按上一级 README 启动 ASR。在 Jetson 本机浏览器访问：

**http://127.0.0.1:8000/test/**

不要直接双击 `index.html`，页面需要后台接口。

局域网另一台电脑使用 SSH 转发（在那台电脑上执行，窗口保持打开）：

```bash
ssh -N -o ExitOnForwardFailure=yes -L 18000:127.0.0.1:8000 nvidia@192.168.1.204
```

然后在那台电脑浏览器访问 **http://localhost:18000/test/**。如本地 18000 端口已被占用，请换一个未占用端口，并同步修改浏览器地址。调试页面与接口只接受本机连接及 localhost/回环 IP 的 Host；不能直接使用 `https://192.168.1.204:8444/test/`。手表继续使用原有 WSS 地址，不需要访问调试页面。

## 调试流程

1. 查看“后台已连接”和模型状态；在线设备只统计已经通过认证的 WebSocket 连接。HTTP 上传是短请求，出现在采集记录中。
2. 点击“开启调试采集”，再在手表上开始录音。无需修改手表协议或密钥。
3. 在“采集记录”选择请求。设备 ID、服务端认证的来源、会话 ID、请求 ID 分别显示；不同设备即使使用相同请求 ID 也有独立记录。
4. 查看音频长度、临时/最终文字、各句的 utterance ID 及延迟。每句临时文字会被新版本替换，最终结果覆盖该句临时结果。一个请求中有多句时逐句展示。
5. 点击“加载音频快照”播放并绘制波形；录音继续时可再次点击加载最新快照。下载 WAV 可直接播放，下载 PCM 供固件调试。浏览器下载文件是用户手动保存，需要自行删除。
6. 查看下方时间线定位认证失败、协议错误、超时、语音检出、停止、取消或断开。时间线保留最近 300 条元数据，不记录密钥及语音正文。
7. 调试结束点击“关闭并清空”。

## 音频到底是什么

- WebSocket：保留服务端收到且通过格式、序号与速率检查的原始 PCM，去掉每包前 4 字节的序号；未做降噪、重采样或 VAD 裁切，包含收到的静音。无法记录未到达服务器的音频或非法包。
- HTTP：保留合法 WAV 中的 PCM 音频数据，WAV 的附加元数据不保留。
- PCM 统一为 **16000 Hz、单声道、有符号 16-bit、小端**。WAV 下载只在同一份 PCM 前添加标准文件头。
- 识别文字为服务实际返回给客户端的文字，已经过简体转换；不会显示未发送的旧结果、被取消的结果或内部 Whisper 的转换前正文。
- 中途开启采集的正在录制请求，会从下一有效音频包开始采集并标记“部分采集”；过去的音频无法恢复。录音结束后再开启不会恢复旧文字。
- 调试记录以整个 start/stop 请求为单位；VAD 可能将它分成多个识别句子，因此下载音频长度与单次 Whisper 输入长度不一定相同。

## 内存、隐私与生命周期

默认不采集音频及文字。每次开启最长 10 分钟，可暂停或提前清空；暂停/到期后不再采集音频和文字，已有记录暂时保留。要完整采集下一次录音，请在开启后重新开始一个录音请求。

每条记录从创建开始保留最多 10 分钟，最多 20 条，原始音频合计不超过 16 MiB，达到上限淘汰最早记录。到期记录在读写时移除，后台另每 5 秒清理一次，即使关闭页面也会继续清理。每个请求最多保留 60 秒音频、100 个分句，每条文字最多 8192 字符。

音频和文字仅保存在当前服务进程内存，服务重启、点击清空或记录到期后无法恢复。不会写到服务日志或自动生成录音文件。关闭浏览器本身不会立即停止采集，请点击暂停/清空；到期会自动停止。

调试接口只允许本机访问，同源检查及随机控制令牌用于防止其他网页开启采集。能访问本机账户或 SSH 隧道的人仍能查看调试数据；不要把该页面反向代理到公网，也不要在代理中伪装成 localhost。

## 页面显示范围

接收包/字节为当前 ASR 服务进程累计值；GPU 使用率是系统可用时的整块 GPU 负载，可能包含 Gemma 的工作量，不是 ASR 独占负载。不支持时显示“不支持”。平均最终延迟为 WS 最终识别从进入队列到返回的耗时，包含排队，不包含此前等待说话和静音的时间。错误率为识别队列统计，不等于全部协议错误率；协议错误见事件时间线。重启后累计值清零。

调试采集不会改变手表、本地或后台任务的优先级，不会向 HA/Gemma 发送控制请求。

## 文件与接口

- `index.html` / `style.css` / `app.js`：页面，无 CDN 和构建步骤。
- `../debug.py`：有界内存采集与受保护的本机接口。
- `GET /test/api/state`：采集状态、记录摘要、元数据事件与当前控制令牌。
- `POST /test/api/control`：JSON 如 `{"action":"start"}`（action 可选 `start`、`pause`、`clear`），必须携带 `X-ASR-Debug-Token`。
- `GET /test/api/records/{id}`：单请求详情与分句识别文字。
- `GET /test/api/records/{id}/audio.wav` 或 `audio.pcm`：当前有效音频快照；过期/清空返回 404。
- 健康及队列统计复用 `/health`、`/metrics`。

此处接口用于人工调试，不替代手表协议。固件仍按上一级 README 的 `/ws/asr` 协议实现。
